REST API для складского учёта

Разработал тестовый сервис для учёта товаров на складе на Python и FastAPI. Реализовал добавление, поиск, изменение и удаление товаров, проверку данных и обработку ошибок. Использовал SQLite для хранения данных и pytest для проверки работы API.

Технологии: Python, FastAPI, SQLite, pytest.
